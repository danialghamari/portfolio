# Professional Work

| Project Link | Completion Date | Tools and Areas of Analysis | Project Description | 
|---|---|---|---|
| [Efficient simulation of (quantum) chemical reactions](https://github.com/danialghamari/MASH-TPS/) | May 2026 | Python, PyTorch, HPC, Linux/Bash | Developed and implemented an end-to-end enhancing pipeline for efficient modeling of nonadiabtic transitions. The pipeline encompasses the simulation stage, combining a mathematically rigorous approach (MASH) with TPS, to efficiently generate a large statistical ensemble of reaction pathways. Our pipeline demonstrated 10x speedup over alternative methods (e.g plain MASH simulations). Then, it performs data analysis of these pathways in the feature space to extract the various reaction descriptors, e.g kinetic rate. Furthermore, I investigated the Neural Network classifiers as a potential method to bypass the simulation stage. However, it did not prove sufficiently robust. This work culminated in an academic publication: [doi: 10.1063/5.0321299](https://doi.org/10.1063/5.0321299) |
| [Simulation of biomolecular reactions with ML and quantum computer](https://github.com/danialghamari/gTPS) | Nov. 2023 | Python, Sklearn, DWave Ocean Suit, HPC, Linux/Bash | Designed, engineered, and deployed a novel framework for the study of biological macromolecules reaction. This framework integrates an ML-enhanced Molecular Dynamics method, with mathematics of nuclear physics, and quantum computing to model reactions that takes specialized supercomputers (Anton) 3 months with regular Molecular dynamics. The results have been published as articles in [Scientific Reports](https://doi.org/10.1038/s41598-022-20032-x) and [JCTC](https://doi.org/10.1021/acs.jctc.3c01174) journals. |
